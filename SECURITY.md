# Security policy

This is a static site served from GitHub Pages. It runs no server code and stores no user data, so most reports will be about a dependency, the build, or the deployment workflow. Those still matter, and they are welcome.

## Report a vulnerability

Report privately, through either channel:

- [Open a private vulnerability report](https://github.com/svyatov/svyatov.com/security/advisories/new) on GitHub. This needs a GitHub account and keeps the report visible only to you and the maintainer.
- Email leonid@svyatov.com.

Do not open a public issue for a security problem.

## What to expect

You get a first reply within 7 days. It says whether the report is accepted and, if it is, what the fix plan is. If you have heard nothing in 7 days, send the report again by the other channel.

A fix ships as a normal deploy from `main`.
